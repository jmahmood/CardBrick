# Tier 3 — Narrative (P181–P240)

**Before generating from this file, read [`00-generation-guide.md`](00-generation-guide.md).**

`tier: "narrative"` for every item generated from this file.

Bounded past events, background, sequencing, recent past, duration,
reporting, and problem narration — for explaining what happened once
basic interaction is solid. Mostly A2–B1 gate. Preterite/imperfect
(`PT`/`IM`) contrast is the dominant grammar point here; it's a
*tense* contrast rather than a discrete right/wrong rule, so it makes
weaker MCQ material than tiers 1–2 — **skip MCQ for most of this
tier unless a row's constraint is genuinely binary** (e.g. an `AGR`
or `PREP(x)` tag). Favor `production` items.

Suggested first batch: P181–P200 (preterite/imperfect core).
