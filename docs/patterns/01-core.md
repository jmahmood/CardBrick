# Tier 1 — Core (P001–P100)

**Before generating from this file, read [`00-generation-guide.md`](00-generation-guide.md).**

`tier: "core"` for every item generated from this file.

Identity, location, possession, everyday action, basic modality,
liking, opinion, questioning, and simple information exchange — the
highest-return foundations for rapid production. Mostly A0–A1 gate;
this is where a learner spends the first week. Good source of MCQ
material: SER/EST, GUS, and PA contrasts are dense in this tier.

Suggested first batch: P001–P020 (ser/estar/hay core).
